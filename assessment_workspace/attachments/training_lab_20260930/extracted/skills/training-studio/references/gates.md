# Gates
**Objective critique (blocked):** any stratum whose gap to floor is below the MDE at its test_n (professor). Everything else in the critique routes.
**Before run (blocked):** schema failure; materials index missing; objective count ≠ index count per source; stratum without resolvable test_set_ref; acceptance not two-dimensional; material missing class/lawful basis/hash/receipt; recipe seat filled without an attached comparison; verdict without confirmer or with a non-adopted `adopted`; any decision field in inputs; literal numbers in the plan.
**After run (blocked):** run refused (manifest refusals > 0); notebook chain broken; manifest < 100% classed; stub run without stub=true or with a status other than stub/interrupted; interrupted run without a partial_ruling_ref; a stratum without both examples-to-accuracy-floor and examples-to-coverage-floor and a binding dimension; comparison not tested against objective.non_target_regression_max; quote range that is neither a statistical CI nor a class-estimated indicative band; a decision in the record; a stratum missing from calibration; an arm without M-a, M-b and compute-to-convergence; a comparison verdict not left to the Owner; a quote without CI; an over-cap quote without routing.
**Report (blocked):** critique, diagnosis, operational plan, value case and four-lens limitations sections missing (a run that did not reach them says so under the heading); manifest, notebook or review.html missing; report does not reference the per-example manifest; stub not declared; a stratum omitted; a stated verdict; WPW-8 section missing; no receipt lines; quote exceeding available material.
**Review (finding-not-blocking):** CI-fixture base model; strata unreachable within available material; milestone owners.
