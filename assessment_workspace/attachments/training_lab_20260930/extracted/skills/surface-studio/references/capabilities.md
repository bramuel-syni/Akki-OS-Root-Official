| Capability | Demonstrated by |
|---|---|
| Role fitting | Same page state, different role → different lead, voice, cap and copy (eval: role switch re-keys and strikes) |
| Move selection | Lead move per page policy, overridden only with a recorded reason |
| Delta narration | prior → current since date; a cause only with a causal receipt (board360 B3 cites R06) |
| Trigger discipline | Triggers only from decisions pending, advisories, Watch records; phrased as waiting-on, never as instruction |
| Silence surfacing | Unmeasured territory has its own block, hatched, with what closes it |
| Editorial economy | Every block within the role cap; system notes counted separately |
