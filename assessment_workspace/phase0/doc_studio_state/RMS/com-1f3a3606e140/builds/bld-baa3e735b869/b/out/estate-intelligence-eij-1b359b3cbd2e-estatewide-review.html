SITUATION
RMS holds 175.0 TiB across its databases, object store and file shares: 130.8 TiB in 106 object-store buckets, 43.9 TiB in file shares and 0.3 TiB in 20 databases holding 1006 tables. The owner has declared every right to use the data established, so rights are settled and gate nothing here.
COMPLICATION

QUESTION
What should the owner do first to cut cost, prepare the data and stand up the first products?
ANSWER
Close the access and inventory gaps first. Then test the idle-bucket archive move against storage class, read demand and real tariffs. Then prepare three bounded product pilots, with de-identification or aggregation as a preparation step. Databases offer only 15.2 GiB of reclaim, 4.3% of database bytes.

PLAIN ENGLISH
What the terms in this pack mean
Reclaimable
Space that could be removed or stored more cheaply once the check named beside it has been done. It is not space already freed, and it is not a guaranteed saving — the monthly figures are upper bounds at list prices.
Cold (not written for over a year)
Nothing new has been written to that bucket or table for more than a year, judged by the newest write date we could see. It says nothing about whether anyone still reads it — that was not measured.
Duplicate candidate
Two objects whose size and storage fingerprint (ETag) match inside the same store. For large uploads that fingerprint is not a content hash, so a candidate must be confirmed by hashing before any copy is removed.
Exact duplicate rows
Database rows that are identical in every measured column. 'Normalised' duplicates also match after trimming spaces and case.
Degraded row
A row whose worst column shows damage: text cut short, a placeholder such as 'N/A' or 'test', an invalid format, stray whitespace or garbled characters.
Empty required-looking fields
Blank values in columns whose name or pattern suggests they should always be filled (for example an identifier or a date). The database may not formally require them; the census flags them so an owner can decide.

PLAIN ENGLISH
What the terms in this pack mean
Dead column
A column that is empty on practically every row: schema carried without data.
Personal-data marker
A sampled value that looks like an email, phone number, national ID or similar. It is a condition of the data, not a judgement about rights — the owner has declared all rights established.
Archive-class storage
A cheaper storage tier for data that is kept but rarely opened. Retrieval is slower and carries its own fee, which is why the saving is stated as an upper bound.
Proposed destination
Where this pack suggests data should live or how it should be tiered. Every destination here is a proposal for the executive to approve; this pack moved and deleted nothing.
Speech hours (estimate)
Recorded hours multiplied by the share of two-second windows the admitted music detector did not call music. Silence is set aside first.
Agrees with folder
The share of labelled windows (or transcript passages) where the model's language label matched the folder the recording was filed under. It is a model reading, not a human verification.

PLAIN ENGLISH
What the terms in this pack mean
Declined to label
Windows where the language model's confidence fell below its threshold, so it gave no language rather than guess.
Scripted day / bulletin hour
A calendar date on which a station has at least one news script in the archive, and the distinct hour slots scripted that day. The archive does not carry a script for every hour of every day; the tables show exactly which days and hours it does.
Receipt
The retained Akki record (census run, GPU job or database reading) that every figure in this pack is traced to. The appendix lists them; the workbook carries the row-level evidence.
Header-measured hours
A duration estimate based on available file headers and per-folder extrapolation for unprobed files. Probing is incomplete; some durations themselves use bitrate estimates. This is not an exact count of decoded estate hours.
95 % interval
A sampling-uncertainty range produced by a method intended to cover its target in 95 % of repeated samples under its assumptions. It does not cover model error, failed reads, unmeasured folders or inaccessible content. Whole-folder reads remove sampling error, not measurement or classification error.
Key refused (403)
The census key can list the bucket but is refused when it tries to read any object. Those files are counted but nothing about their content is estimated. The fix is an access grant on the owner's cloud account, not a change to the census.
