## §B · Wave-honest limits

1. **V121b recording-modality is a REF-carrier only.**  `RecordingEvidenceLeaf.plays_at_timestamp` is an opaque timestamp string · `recording_provenance_ref` is an opaque ref.  No audio bytes cross the seam.  Actual playback is a Watch/UI concern.
2. **V119c internals-projection refusal is NAME-SCAN based.**  Forbidden-field-name closed-set is fixed at authoring time.  A benign-named field carrying an internals-shaped value is NOT caught by name-scan alone.  Documented in `assert_no_internals_projected`'s docstring.
3. **V122c reads-only defence is ALLOW-LIST based at authoring boundary.**  Type-name allow-list of five carriers authored this sub-wave.  A carrier legitimately named `CommissionViewProjection` that computed new totals internally is NOT caught by name-scan alone · caller-side integration tests carry the total discipline.
4. **V120b defence-in-depth in render.**  Even if a caller bypasses the CP-M6-9-1 factory (e.g., constructs a `CommissionViewSnapshot` directly with an unagreed milestone list), `render_commission_view` re-checks and refuses.  Family-catch preserved.
5. **No LLM / HTTP / filesystem / network.  Case-agnostic.  §3.1 P038 preserved.**  Synthetic fixtures only in tests.
