> Standing Order §6.9 — Function is the objective; adherence is how it's kept honest
>
> Binding on E1, the auditor, and this desk from receipt. Amends prior rulings where named.
>
> The direction. The platform exists to do work on real estates for real tenants. Governance is what makes that work trustworthy — it is not the work. From here, every ruling that refuses, holds, or gates must state in one sentence the material objective it protects. Where canon provides a marker that lets function proceed transparently — unmeasured, INFERRED, honest-gap, the fallback markers — the marker is used and the work continues; refusal is reserved for the cases where a marker cannot make the state honest. A ruling that cannot name what it protects is withdrawn.
>
> 1. The change-mechanism ladder. The weight of the mechanism matches the blast radius of the change: Behaviour-changing rules — TCB, custody, the Watch, approval logic: ceremony with countdown. Unchanged. Configuration and entries — catalog rows, credit rates, licence fields, allow-lists, ceilings: a receipted owner act, prospective, immediate. DAP-26's no-retroactivity holds; the countdown does not apply. ENT-10, ENT-11, ENT-12 are re-classed here. Copy — fixed strings: a contract-version PR with the substitution-rule update. Ceremony only for governance copy — the refusal card, the honest-gap strings. CON-2 is re-classed here. Scaffolding — test guards, fixtures, floor assertions: owner ruling, applied at the next boundary. R-91 ε applies at E1's next boundary, now, not at the horizon; the five wrapped baselines retire on that seal.
> 2. Sealed-additive class. Additive members on a sealed class are permitted when no existing member changes, the sealed tests are byte-identical and green, and the diff is banked with the seal. No wrapper, no ceremony. If the PrincipalRequestContext unwind has not landed, cancel it; if it has, leave it.
> 3. The HF hold is re-scoped to the hazard. The hazard is presentation of the leaked credential, not the host. Public, unauthenticated weight pulls proceed now — the Local serving path unblocks today. The hold applies only to operations that would present the old token; the three-step revocation still closes it.
> 4. Language identification — labels flow now. Register Whisper language detection (MIT) and SpeechBrain VoxLingua107 (Apache 2.0) with hash and licence file as the registration act. Run them on every segment; write each label as an overlay detection with model entry, confidence, execution mode, and regime pre-admission — replacing the refusal marker with a real per-segment label marked INFERRED. Build the admission gate alongside on tenant-labelled real segments, threshold DEFAULT ≥90%, abstain-below-confidence recorded as unmeasured. When a model clears, its labels promote from overlay to measure by a receipted act; nothing is relabelled.
> 5. Continuity over the letter of §4. A private mirror of programme/track-a and master, pushed at every milestone seal. §4's purpose — no unreviewed public code — is preserved; its letter is amended to permit the private remote.
> 6. Specifications corrected where they over-reached. CON-20: a content receipt on change of hook, not per render. The ranking is deterministic and re-derivable. SFP-8: E1 measures reproduction on the actual hardware before any refusal path is wired; the tolerance is ruled from the measurement. Serving degrades with a marker; gates refuse. ENT-16 keeps its rule and gains its seed: a pilot licence object created at tenant creation for RMS, DigiCow, and AKKI-TEST — Compute dial Managed, Frontier dial Your Keys — so every model call resolves from the first day.
> 7. Tenant separation proceeds as ordered, with the approving authorities as named — Fred Afune, Muthoni Kiarie, Samuel Kibacia for RMS; Vincent Kimani, Peninah Wanja for DigiCow — the any-one decision rule, and the isolation sweep as exit evidence.
> 8. The census proceeds in its three waves — complete the walk with the unmeasured register, the full B3 dimension set with the defensibility matrix and sensitivity classification, then the perception pathway — and language labels from item 4 enter it as overlay from the first run.
> 9. The audit runs as ordered under Standards v2 and §6.8; nothing here changes its target or its independence. What still reaches the owner, unchanged: tier-4 forks batched at seals; credential drops; the ratification signature.
>
> What this desk holds itself to: the one-sentence objective on every refusal; the marker over the refusal wherever canon provides one; and, where a ruling proves to have blocked function without naming what it protected, its reversal without being asked. Continue.
