## OBJECTIVE

Implement the Conditioned Ideation Faculty (CIF) exactly as canon defines it, per SO §6.4 pre-ruling verbatim. CIF is a learned ideation faculty structurally placed OUTSIDE the TCB, whose sole job is to author proposals — never decisions. Every CIF-authored idea passes through a deterministic single-experiment acceptance point (BR-9.2, IN TCB) before it can affect anything downstream. The acceptance point routes accepted proposals to either the L-4 research loop (A5.22) or the L-5 capability register (A20.16); everything else refuses. CIF's halt state (DET-1) is independent of the Targeta run it feeds. Nothing beyond this scope is in M16 — any expansion is a fork.
