# M13 · Tier-2 Standards (Post-TCB-Governance)

## OBJECTIVE

Land the tier-2 production-grade standards that the platform must satisfy at end-of-build: envelope-encrypted KMS with per-tenant keys and 90-day rotation (the full key hierarchy the M12b-W1 minimum Ed25519 primitive anchors); conventional OpenTelemetry instrumentation across the chokepoint, ledger, and Watch surfaces; conventional Terraform IaC for reproducible environment builds; and B.10 runbooks for the SEV-1 and operational break-glass paths. M13-W1 (TCB governance regime · TCB.yaml + akki.arch AST-based cross-import checker) is already SEALED at Commit-A `71faac1c` / Commit-B `96577787` (2026-09-17T~13:46Z) — this card covers the four REMAINING sub-waves.

## MUST DO

1. **W2 · KMS envelope + per-tenant keys + 90-day rotation** — canonical envelope-encryption primitive with per-tenant master keys and 90-day rotation cadence. Extends the M12b-W1 Ed25519 primitive (`services.watch.signature_primitive`) with a KMS hierarchy: `services.kms.envelope` (data-encryption-key wrapping/unwrapping under a tenant-scoped master key), `services.kms.tenant_key_registry` (per-tenant master key registry keyed by `tenant_id`), `services.kms.rotation_scheduler` (90-day rotation with append-only key-lineage record). Structural role separation: `envelope` never mints tenant master keys; `tenant_key_registry` never wraps data; `rotation_scheduler` never decrypts. AST bans mirror the M10-W4 read-only-at-cutover pattern for any pre-existing key-material surfaces. `canon_ref: §6.4 pre-ruling 4 verbatim ("KMS: envelope encryption, per-tenant keys, 90-day rotation (R-4)") + Canon 8 §W10 (watcher-watched-from-outside · Watch key stays scope-bounded to Watch trust boundary) + Canon 8 §W11 (one-task-one-identity · each KMS role is one identity).`

2. **W3 · OpenTelemetry conventional instrumentation** — OTel spans + metrics + logs on the chokepoint (`services.chokepoint.llm.invoke`), the unified ledger writer (`services.ledger_writer.main.append_intent`), and the Watch input seat + emitter (`services.watch.input_seat` + `services.watch.verdict_interface`). Trace attributes carry `tenant_id`, `run_id`, `event_type`, `decision`, `reason_code`. No PII / no credential material in span attributes (§4.1 §E discipline extends to telemetry). Structural test: AST-scan asserts every span attribute name is in a closed allow-list `TELEMETRY_ATTR_ALPHABET` (mirror of Canon 8 §Line 31 closed-registry pattern applied to OTel). `canon_ref: §6.4 pre-ruling 4 verbatim ("OTel and Terraform: conventional") + §4.1 §E (never in test docstrings, never in logs) + Canon 8 §Line 31 (closed-registry doctrine).`

3. **W4 · Terraform conventional IaC** — reproducible-environment declarations for the FastAPI pod, the MongoDB per-tenant provisioning target (per B.3/B.7), the KMS master-key store, and the OTel collector. Every resource has a Terraform `moved{}` block for renames (never destroy-recreate) — mirrors Canon 8 §W3 destroy-does-not-exist doctrine transplanted to IaC. Structural test: `notes/M13_W4_terraform_manifest.yaml` names every resource + its owning module + its Canon anchor + its rotation cadence (if any). `canon_ref: §6.4 pre-ruling 4 verbatim ("OTel and Terraform: conventional") + Canon 8 §W3 (destroy-does-not-exist · applied to IaC via moved{} blocks).`

4. **W5 · B.10 runbooks** — one runbook per SEV-1 wire that M10-W3 sealed (chain-break page → security-group), one runbook per KMS rotation event (W2 · scheduled + on-demand), one runbook per Watch signal that reaches the enforcer (W1 severance). Each runbook lives at `notes/runbooks/RB_<code>_<name>.md` with a fixed 7-section shape: TRIGGER, EVIDENCE, VERIFY, DECIDE, ACT, RECORD, POSTMORTEM. Structural test: every entry in `services.watch.sever_signals.SEVER_SIGNAL_REGISTRY` and every SEV-1 wire has ≥1 runbook that cites it. `canon_ref: §6.4 pre-ruling 4 verbatim ("Runbooks per B.10") + Canon 3 §B.10 (runbook obligations) + Canon 8 §W1 (evidence-never-action · runbooks are evidence-shaped).`

## MUST NOT

- Import KMS primitives from a caller that lies outside the Watch/enforce trust boundary. `canon_ref: Canon 8 §W10 (watcher-watched-from-outside · key material never routed to callers) + §W11 (one-task-one-identity).`
- Route OTel span attributes containing PII / credential material / raw canonical bytes of ledger rows (payload_ref hash is fine; the row itself is not). `canon_ref: §4.1 §E verbatim (never returned, never logged, never in test docstrings).`
- Ratify Terraform that destroys a resource where a `moved{}` block would suffice. `canon_ref: Canon 8 §W3 verbatim (destroy-does-not-exist · applied transplanted to IaC).`
- Author a runbook whose ACT step contains an autonomous action against production data (runbooks are evidence + human-decide + human-act; never machine-act). `canon_ref: Canon 8 §W1 (eyes-never-act) + Canon 3 §B.10 (evidence-then-decide).`
