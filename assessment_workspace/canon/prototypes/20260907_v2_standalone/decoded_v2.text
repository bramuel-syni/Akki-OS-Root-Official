approved to service only after all six hold, and it leaves the day one stops holding. There is no partial approval and no exception path. The minimum for each check was set at founding and has not moved. Recall on held-out set 0.80 required Of the answers that were there to find, how many did it find? Measured on material the model never saw while training. Precision on held-out set 0.85 required Of the answers it gave, how many were right? A model that guesses freely scores well on recall and badly here. Calibration check 0.05 max error When it says it is 90% sure, is it right 90% of the time? Legacy summariser failed here at 0.11 — it grew surer while getting no better. Fairness slice review 0.10 max spread The same question asked across every language, region and customer segment held. The gap between the best and worst slice is the score. swahili-doc-classifier-v1 was refused at 0.16. Drift stability 0.75 required Re-run every month against current material. receipt-classifier-v2 returned 0.68 on Aug 29 and was out of service the same day. Explainability sample 95% traced A sample of answers, each traced back to the source passage behind it. A claim that cannot be traced counts as untraced. Answered from memory, or worked out fresh Every question is checked against answers already given before it reaches a model. If the same question has been answered and the material behind it has not changed, the stored answer is returned — answered from memory. If not, the model works it out — worked out fresh. This month 76,400 answers came from memory and 52,000 were worked out fresh. Memory carried 60% of answers on 18% of spend, at a median 0.6s against 5.2s. That gap is the whole reason a memory sits in front of the models. What is stored is the answer and the question that produced it — never source rows. A stored answer is dropped the moment the material behind it changes, which is why the share moves month to month rather than only climbing. Masking and trust receipts Identifying fields are replaced with placeholders before a call leaves RMS, restored on the way back inside the estate, and the placeholder-to-value map is destroyed within milliseconds. Four stages, in that order, every time: de-identified, invoked, re-identified, mapping envelope destroyed. Each call writes one trust receipt recording that the sequence ran and which pathway it took — Synthesis for a model that composes text, Perception for one that returns a label or a vector. The receipt count always equals the call count: 128,400 calls this month, 128,400 trust receipts. They are the same fact stated two ways, which is why context masked reads 100% and has no trend to show. A receipt carries no field value. It proves the process happened, nothing more — and 100% is a hard line with no exception path, so a figure below it would be a violation, not a variation. Why models refuse When a model cannot answer responsibly it declines rather than guesses. There are three reasons, each named after the gate that produced it, and a refusal is written to the trail with that gate. 1,842 answers were refused this month. Not enough proof 811 · 44% It could not find a passage it was allowed to cite. The honest answer is that it does not know — most of these trace to the sparse pre-2019 branch record. Not allowed to see it 663 · 36% The asker’s permission does not cover the material the answer would need. The model is not told what it is missing, only that it may not read it. Outside what it’s allowed to do 368 · 20% The question falls outside the actor’s own declared purpose — Vendor Risk Monitor · ACT-1043 asking beyond its declared supplier set accounts for 41 of these. Refusals are counted as work done, not work lost. Nothing is reclassified after the fact, which is why the three reasons sum to the total exactly.
