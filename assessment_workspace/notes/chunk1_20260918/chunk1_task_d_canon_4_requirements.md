## Part I · The Chain

- **C4-R-001 · Doc 4 scope.** Specifies Mtafiti (measures) · Targeta (targets) · Solva (reasons) + extraction stack + transform layer + model ladder + training + quality + economics. *Canon 4 §1.*
- **C4-R-002 · Production is accountable for one thing.** Estate material becomes governed intelligence at a stated standard, repeatably, with every unit traceable to source. *Canon 4 §1.*
- **C4-R-003 · Three end-to-end properties.** Learning never decides (learned components at 3 named points; each corruptable thing structurally out of reach) · nothing admitted at guessed class (unqualified units never enter evidence partitions) · every output states strongest provenance its form permits, and no more. *Canon 4 §2.*

## Part II · Mtafiti — Discovery and Measurement

- **C4-R-004 · Mtafiti = census + Registry writer.** What exists, at what sensitivity, how defensibly each source can be relied upon; discovers + measures; does not extract/target/govern; runs at standup, kept current by freshness mechanism. *Canon 4 §3.*
- **C4-R-005 · Mtafiti is objective-blind.** Measures estate as it is, without reference to any objective; targeting + convergence both read one measure serving every objective equally. *Canon 4 §3.*
- **C4-R-006 · Mtafiti measures defensibility, never truth.** Set by claim genre + source standing + corroboration + recency + contested status; targets and floors, never certifies; must fail toward caution. *Canon 4 §3.1.*
- **C4-R-007 · Census walks exhaustively + objective-blind.** One candidate source record per discovered source; enumerates and classifies; measurement follows separately. *Canon 4 §4.*
- **C4-R-008 · Per-source-and-stratum census output.** Volume · media types · languages · era distribution · quality strata · share verified · share personal-data · share licensed-external — and explicitly what has not been measured. *Canon 4 §4.1.*
- **C4-R-009 · Unmeasured is first-class value.** Dimension not measured recorded as unmeasured, never as zero, absent, or clean. A blank reading as clean makes whole instrument dishonest. *Canon 4 §4.1.*
- **C4-R-010 · Every figure carries its method.** Resolves to census run + date + population measured + full-vs-sampled; sampled never presented as full-population. *Canon 4 §4.1.*
- **C4-R-011 · Census sensitivity classification IS the D3 §22.1 entitlement resource attribute.** No second classification for that purpose. *Canon 4 §4.1.*
- **C4-R-012 · Declaration baseline is per-feed, deterministic, low-cardinality, always available.** Never assigned per item (would be human bottleneck); undeclared feed → unknown (conservative), never resolves upward. *Canon 4 §5.1.*
- **C4-R-013 · Inference overlay emits detections only.** Attachment-markedness · detected genre-form label · corroboration value · confidence on each. Genre-form label is a detection, not a verdict. *Canon 4 §5.2.*
- **C4-R-014 · Inference module never imports verdict module, never assigns defensibility class.** Enforced by import assertion. *Canon 4 §5.2.*
- **C4-R-015 · Detect-vs-decide separation rule.** Learning detects · governed matrix decides · declaration baseline floors · admission gate admits. Single rule keeping learning from laundering authority into the measure. *Canon 4 §6.*
- **C4-R-016 · Compose vector = deterministic baseline + admitted detections + deterministic recency + deterministic contested-status.** When overlay not admitted, composition uses baseline alone; Registry records which regime produced a given measure. *Canon 4 §6.1.*
- **C4-R-017 · Decide = deterministic lookup in Qualification Matrix over claim-genre + context.** Returns defensibility class (fact/utterance/non-factual) + rule-reference. *Canon 4 §6.2.*
- **C4-R-018 · Verdict carries rule-reference for audit.** Every class traces to governed rule; detections it consumed recorded alongside; a learned-verdict would rest on a model weight = un-auditable. *Canon 4 §6.2.*
- **C4-R-019 · Matrix read through opaque handle, contains no model.** Governed, versioned, inspectable — verdict issued a year ago re-derivable and explainable today, exactly as reached. *Canon 4 §6.2.*
- **C4-R-020 · Overlay admission gate.** Overlay influences measure only after detection accuracy proven on real material; until it passes, baseline alone; failure of overlay ≠ failure of system — baseline + governed verdict never depend on it. *Canon 4 §7.*
- **C4-R-021 · Registry one-record-per-source.** Carries existence + sensitivity + defensibility measure + freshness stamp; this IS the interface targeting + convergence both read. *Canon 4 §8.*
- **C4-R-022 · Freshness = logged date + structural-delta check.** Drives scoped re-discovery of only affected region + re-runs measure for that region alone; retraction changes contested status. *Canon 4 §8.*
- **C4-R-023 · Stale/un-censused region returns unknown to feasibility query.** Never a fabricated distribution; no objective freezes against unmeasured estate. *Canon 4 §8.*
- **C4-R-024 · Mtafiti calibration posture.** Inferred measure is targeting + flooring prior, never truth verdict; strong enough to prioritise + floor composition, not to certify truth; fails gracefully — mis-scored source = wrong mining order, never claim asserted above class. *Canon 4 §9.*
- **C4-R-025 · Mtafiti invariants (§10).** Census exhaustive + objective-blind; one measure serves every objective · declaration baseline deterministic feed-level always available (undeclared → conservative) · inference overlay emits detections only, never imports verdict logic, never assigns class · verdict is deterministic matrix lookup carrying rule reference, contains no model · overlay influences measure only after admission gate passes; baseline stands alone until then, Registry records which regime · measure never overstates standing, fails toward caution · unmeasured dimension recorded as unmeasured, never zero/clean · stale/un-censused region returns unknown, never fabricated. *Canon 4 §10.*

## Part III · Targeta — Targeting

- **C4-R-026 · Targeta = mining-plan producer.** Reads measured Registry + governing artifact; decides where to mine and in what order within budget; does not extract, does not govern. *Canon 4 §11.*
- **C4-R-027 · Targeta is the one platform component permitted to learn.** Most of its spec exists to bound that learning so it never narrows what an objective may reach. *Canon 4 §11.*
- **C4-R-028 · Two-half anchor.** (a) Do the job better — reach objective-satisfying floor-meeting intelligence in fewer mined units · (b) Never narrow what the objective may reach — floor inviolable, coverage never silently reduced for efficiency. *Canon 4 §11.1.*
- **C4-R-029 · Two-layer structural separation.** Objective-conditioned yield (competence · permitted) vs unconditioned source-preference (bias · denied). Yield layer granted the first, structurally refused the second. *Canon 4 §12.*
- **C4-R-030 · Eligibility core reads Registry + artifact, applies floor as hard filter, ranks by fixed inspectable function.** Contains no model, no learned weight. *Canon 4 §13.*
- **C4-R-031 · Below-floor source excluded, full stop.** Not down-weighted, not ranked last — excluded before any ordering; floor is filter, not factor. *Canon 4 §13.*
- **C4-R-032 · Deterministic + reproducible ranking.** Given Registry state + governing artifact + yield-layer version, same plan every time. *Canon 4 §13.*
- **C4-R-033 · Guard held as a type (§14, 3 properties).** (i) Yield layer input is floor-passing eligible set only — no floor, no raw measure, no eligibility logic · (ii) Output is a permutation of that exact set — no adds, no removes · (iii) Non-permutation output is a type error that raises, not corrects. *Canon 4 §14.*
- **C4-R-034 · Yield layer never called directly.** Called only through boundary function; boundary constructs stripped input, invokes yield, validates permutation before reordering. *Canon 4 §14.*
- **C4-R-035 · Yield-layer admission gate (2 arms, 2nd a veto).** Improving efficiency by starving a class fails regardless of efficiency number; veto prevents silent narrowing. *Canon 4 §15.*
- **C4-R-036 · Failed gate → deterministic core alone runs.** Core never blocked by yield-layer failure; failed gate degrades ordering quality only. *Canon 4 §15.*
- **C4-R-037 · Mining plan is frozen contract with core baseline ranking retained.** Auditor can reconstruct why mining happened in that order; yield-layer influence auditable after the fact. *Canon 4 §16.*
- **C4-R-038 · Two modes.** Portfolio mode (reads whole Registry vs Portfolio Mandate, class-default floor, yield reorders within eligible strata) · Per-run mode (reads Registry vs one Objective Request, applies objective floor as hard filter, weights by relevance, yield reorders by objective-conditioned yield). Both honour floor absolutely, produce reproducible plan. *Canon 4 §17.*
- **C4-R-039 · Targeta invariants (§18).** Core deterministic + no model + never imports yield layer · yield layer imports only boundary types · yield output is permutation (non-permutation raises) · floor is hard filter applied by core (nothing below eligible, nothing re-admits) · efficiency-by-starvation is veto-class failure regardless of measured gain · failed admission gate degrades to core, never blocks. *Canon 4 §18.*

## Part IV · Solva — Depth

- **C4-R-040 · Solva judges reasoning-soundness + preservation-sufficiency + within-defensibility assertion.** The one engine that genuinely reasons; never extracts and never reaches into operator primitives; issues operations, interprets results, governs depth. *Canon 4 §19.*
- **C4-R-041 · Two faculties joined by one-way seam.** Reasoning faculty informs composition freely; its strength is never input to assertion boundary. A conclusion built from utterance-class units is asserted as "X was stated" however overwhelming the evidence. *Canon 4 §20.*
- **C4-R-042 · Seam is a dependency rule, not a convention.** Assertion module does not import reasoning-faculty confidence; reasoning module does not import class computation. Both directions enforced by import assertion. *Canon 4 §20.*
- **C4-R-043 · Reasoning stages are real acts.** Tension = contested material surfaced not averaged (claim + retraction held in view together); Reflection's output includes load-bearing set (units the conclusion actually rests on), the only thing assertion boundary consumes. *Canon 4 §21.*
- **C4-R-044 · Intent audit records declared vs demonstrated frame.** Solva's opening audit treats declaration as declaration never as truth; reconciles declared vs demonstrated across layers; declared search for clarity whose answers reject all candidates but the one arrived with = confirmation, not inquiry. *Canon 4 §21.1.*
- **C4-R-045 · Synthesis never exceeds audited intent.** Sustained declared-vs-demonstrated divergence = second trigger on synthesis gate; surface may reframe honestly in-session; synthesis under unresolved divergence says so in its trace. *Canon 4 §21.1.*
- **C4-R-046 · Admit-time divergence emission surfaces to Watch.** Where D3 §6.1 admission declaration + demonstrated conduct part ways, divergence is emission Watch reads under Doc 8; Solva itself acts on it only as reasoning discipline, never as enforcement. *Canon 4 §21.1.*
- **C4-R-047 · Load-bearing function returns unit references only.** No class decision; a load-bearing function returning a class would collapse the two faculties into one — Solva chooses units, not what they imply. *Canon 4 §22.*
- **C4-R-048 · Assertion boundary — three mechanical rules (§23).** (i) Conclusion inherits floor of load-bearing units' classes (weakest unit sets ceiling for whole) · (ii) Utterance-class conclusion asserted as "was stated", never fact — phrasing is a function of class · (iii) Reasoning strength is NOT an input to class; computation reads governed classes alone. *Canon 4 §23.*
- **C4-R-049 · Laundering unrepresentable, not policed.** "The evidence is overwhelming, assert utterance as fact" cannot be expressed; class function has no parameter through which reasoning strength could enter; signature is the guard; signature assertion in test suite keeps it one. *Canon 4 §23.1.*
- **C4-R-050 · Assertion boundary built first, then reasoner bound to it.** Building reasoner first + adding boundary later would make boundary a filter routable around. *Canon 4 §23.1.*
- **C4-R-051 · Solva reads floor + class-verdict through read-only handles.** Reads them, never sets or relaxes. *Canon 4 §24.*
- **C4-R-052 · Conclusion below floor is refused with structured reason.** States what was asked + supported class + what would raise it; refused visibly, never silently downgraded and served. *Canon 4 §24.*
- **C4-R-053 · Refusal offers exactly three things a person can actually do.** Accept the result as recorded statement · narrow the objective · lower the standard. Anything else = offering what system cannot deliver. *Canon 4 §24.*
- **C4-R-054 · Solva reasons against two bars, both governed by same two-faculty structure.** Only the target differs; at convergence Solva emits defensibility stamp per unit; verdict itself is governed matrix lookup (discovery's domain); refusal reasons recorded in stamp-audit side-channel absorbed by Ledger. *Canon 4 §25.*
- **C4-R-055 · Every extraction-time judgement produces a trace.** Reasoning path across stages + load-bearing units + class computed at boundary + conclusion; carries trace identifier joining to unit-level intelligence + trace lenses + Ledger row's same identifier. *Canon 4 §26.*
- **C4-R-056 · Trace not added later — exists from first commit.** Auditability that justifies letting a component reason at all. *Canon 4 §26.*
- **C4-R-057 · Solva invariants (§27).** Reasons; never extracts / never reaches into operator primitives · two faculties + one-way seam · conclusion's class is floor over load-bearing units' classes; reasoning strength not an input · utterance-class conclusion asserted as "was stated" never fact · Solva identifies load-bearing units, does not choose class · floor + class-verdict read-only · conclusion below floor refused, never silently downgraded · every judgement produces trace · Solva governs depth only; axes never collapse. *Canon 4 §27.*

## Part V · The Extraction Stack

- **C4-R-058 · Stack executes only where Northena Gate routed sub-objective to fresh extraction.** Warm-served answer reads from qualified intelligence, never re-enters stack. *Canon 4 §28.*
- **C4-R-059 · Extraction firing on every query = platform never accumulates.** Exception path, not default. *Canon 4 §28.*
- **C4-R-060 · Pipeline is the same across all modalities.** Layers, unit contract, qualification apply identically to audio/documents/structured/images/etc. *Canon 4 §28.*
- **C4-R-061 · Three layers, single direction of flow.** Each boundary is a contract; worker inside any layer replaceable without layers above knowing. *Canon 4 §29.*
- **C4-R-062 · Normalised unit = frozen contract with flat field names.** Admits structured sources exactly as perceived — a structured record becomes a unit without perception, carrying text modality + free locator. No second intake contract anywhere. *Canon 4 §30.*
- **C4-R-063 · Every unit carries five rings + re-extraction handle.** Rings: content · provenance · relational edges · context · defensibility. Handle: without it provenance is a label; with it a unit can be regenerated from source and compared. *Canon 4 §30.*
- **C4-R-064 · A unit that cannot meet evidence standard is recorded as unqualified.** Never admitted at guessed class. Unqualified units never enter evidence partitions. *Canon 4 §31.*
- **C4-R-065 · Qualification is a partition, not a read-time filter.** Property is architectural — follows from qualification + assertion boundary together; does not depend on anyone noticing a source was degraded. *Canon 4 §31.*
- **C4-R-066 · Work runs in batches; tripped rail holds at the seam.** Hold visible on the run inline; resolution is single-reviewer act in governance; run reflects it the moment it lands; never silently dropped or silently passed. *Canon 4 §32.*
- **C4-R-067 · Budget ceiling is a hard stop.** Nothing past ceiling is billed. *Canon 4 §32.*
- **C4-R-068 · Long work survives interruption.** Jobs checkpoint; re-dispatch is idempotent (same job twice ≠ 2 unit sets or 2 charges); completion judged from durable artefacts not status message. *Canon 4 §32.*
- **C4-R-069 · Perception work crosses as frozen job + returns as frozen result.** Job: what to read + standard + model registry entry. Result: what was read + confidence distribution + execution mode + grounding markers. *Canon 4 §33.1.*
- **C4-R-070 · Grounding markers resolve to position in source.** Timestamp span in audio; page + region in document. Makes re-extraction handle real for non-text material. *Canon 4 §33.1.*
- **C4-R-071 · Model registry entries are versioned dependencies with rights posture.** Every model registered with hash + licence; model whose licence has not been verified does not run. *Canon 4 §33.2.*
- **C4-R-072 · Registry additive; result records the entry it was produced under.** Result from last quarter remains fully interpretable after registry has grown far past it. *Canon 4 §33.2.*
- **C4-R-073 · Execution mode is explicit + attributable per job.** Same pipeline runs on general-purpose or accelerated hardware behind one seam; result contract unchanged by execution mode — hardware is implementation fact. *Canon 4 §33.3.*
- **C4-R-074 · Perception calls route through boundary governor.** Speech + vision providers consumed through SyniSense's perception router — material crossing model boundary is receipted whatever the modality. *Canon 4 §33.3.*

## Part VI · The Transform Layer

- **C4-R-075 · Two stages: mine then transform.** Mine = extraction to qualified intelligence (sized by reach); Transform = qualified intelligence into declared output, entirely inside the system. *Canon 4 §34.*
- **C4-R-076 · Transform's input is stored qualified intelligence, never live tail.** Transforming from running tail = output whose composition depends on when it was taken. *Canon 4 §34.*
- **C4-R-077 · Two services · Build-the-asset + Serve-the-objective.** Build = Mtafiti + extraction (Parts II + V); runs objective-blind, ends at qualified unit, stops. Serve = Targeta + Solva + SyniSense composing answer against frozen objective. Neither is peer — Serve depends entirely on what Build produced; Build has no dependency on Serve. *Canon 4 §34.1.*
- **C4-R-078 · First seam = the unit.** Normalised unit of §29 is the frozen interface; Build writes it and advances no further; Serve reads and never writes. *Canon 4 §34.2.*
- **C4-R-079 · Warm check runs first, always.** Where objective servable from existing units, Serve serves warm and Build never invoked; where not converged, Serve calls Build's machinery — exactly one path exists to build a unit, no shortcut. *Canon 4 §34.2.*
- **C4-R-080 · Second seam = governed boundary.** Identical boundary of D3 Part III + D7 Part II; SyniSense chokepoint + answering service's admission + grounding on the way out. Every answer crosses two contracts: unit + boundary — no third path. *Canon 4 §34.3.*
- **C4-R-081 · Provenance bound.** Transform produces shaped output only where declared standard survives it; each form carries preservation rule shaping wizard evaluates before running; refusal happens during shaping with a path forward, never at execution. *Canon 4 §35.*
- **C4-R-082 · Surfaces render outputs; never re-shape them.** A different form or grain is a new objective; prevents analytics drift through export. *Canon 4 §35.*
- **C4-R-083 · Five output forms.** Qualified data (per-claim provenance) · Composed conclusion (floor-over-load-bearing · Solva boundary applied) · Knowledge artifact (structured composite · completeness-sampled) · Callable skill (ingredient manifest — calling pattern destroys per-claim resolution) · Model (training destroys per-claim provenance entirely; remaining = training-data unit set + MOAC criteria). *Canon 4 §36.*
- **C4-R-084 · No form is mis-promised.** Shape that cannot carry provenance at all is not offered as output form. *Canon 4 §36.*
- **C4-R-085 · Acceptance is automatic + non-negotiable.** Trained model must (i) beat base on target stratum, (ii) damage nothing else beyond bound, (iii) evaluate on held-out uncurated, (iv) carry complete lineage with inherited rights, (v) calibrate, (vi) ship with evaluation card — all six or does not enter registry. No person sits in that path. *Canon 4 §37.*
- **C4-R-086 · Analyst-observable acceptance surface.** Staged progress with current stage live · candidate's error against base as checkpoints land · each check moving from pending to measuring to settled with real number attached. Rail-tripping batch holds like any other. *Canon 4 §37.*
- **C4-R-087 · Lineage is visible including failures.** Rejected version stays on the shelf permanently with reason; resubmission creates next version in same lineage + re-runs every check. *Canon 4 §37.*
- **C4-R-088 · Base weights do not change; adaptation bounded + versioned per instance.** Capability replicates across instances without forking a core. *Canon 4 §37.*
- **C4-R-089 · Blinded comparison protocol.** Arm identity concealed at scoring · outputs presented in randomised order + normalised to remove arm-identifying form artefacts · identity unsealed only after scores fixed · leakage check run before unsealing. *Canon 4 §38.*
- **C4-R-090 · Leakage check is a probe.** Can the arm be identified above chance from the blinded outputs alone? Concealing label alone insufficient — identity leaks through form/ordering/length as readily as through a name. *Canon 4 §38.*
- **C4-R-091 · Measurement discipline binds evaluation.** Measurement contract fixed before run · executes real serving path not shortcut · selection + test manifests disjoint and hash-verified · report fields explicitly nullable — an uncomputed metric never misread as an empty one. *Canon 4 §38.*

## Part VII · Economics

- **C4-R-092 · Cost measured, price shaped; the two never confused.** Throughput + unit yield + cost-per-qualified-unit come from instrumented runs on real material — no invented figure ships as though it were real. *Canon 4 §39.*
- **C4-R-093 · Price is configuration, not code.** Versioned price models, swapped at control surface; every quote stamps model version that produced it. Learning-phase quote is structurally non-precedent — explicitly time-boxed, cannot be pointed to later as commitment. *Canon 4 §39.*
- **C4-R-094 · Delivery time is the capacity signal a requester sees; hardware numbers never surfaced.** Two cost classes: warm (served from qualified intelligence held) = fast; fresh (requires extraction) = queued/slower/priced higher. *Canon 4 §39.*
- **C4-R-095 · Quote instrumentation understands pricing dynamics, doesn't score individual quotes.** Per quote: shape + model version + outcome + negotiation-stall dimension + first buyer lever. *Canon 4 §39.*
- **C4-R-096 · Fleet allocation is versioned policy at control surface, managed live by operator.** *Canon 4 §39.*
- **C4-R-097 · Every extension re-quotes.** Extending a running objective generates new quote for the addition; one commitment covering two scopes cannot be reconciled afterward. *Canon 4 §39.*

## Part VIII · The Model Ladder and Training

- **C4-R-098 · Four rungs ordered by cost; selection rule = lowest rung meeting the promise.** Registry's ladder-rung field makes every placement inspectable. *Canon 4 §40.*
- **C4-R-099 · Rung 1 · Deterministic code.** Byte checks, regex, structural walks, contract locks, counting, routing. Near-zero marginal cost; fully auditable; never drifts. *Canon 4 §40.*
- **C4-R-100 · Rung 2 · Classical NLP.** Tokenisation, entity recognition, sentence segmentation, language ID, rule-based tagging. CPU-cheap, deterministic-enough, offline-capable. *Canon 4 §40.*
- **C4-R-101 · Rung 3 · Small owned models.** Estate-fine-tuned perception + domain models — speech, diarisation, classifiers — registry-pinned. Owned, near-free inference in-perimeter; flywheel migrates work down here continuously. *Canon 4 §40.*
- **C4-R-102 · Rung 4 · Frontier LLM.** Open synthesis only; always behind SyniSense; always with lower-rung fallback. Highest unit cost. Every use answers "why not rung 3?" before approved. *Canon 4 §40.*
- **C4-R-103 · Expensive rung architecturally optional everywhere.** Grounding checks are byte-mechanical, explicitly rejecting semantic scoring; every frontier-LLM consumer carries mechanical fallback arm beneath it. *Canon 4 §40.*
- **C4-R-104 · Deflation law.** Every training cycle produces owned models migrating rung-4 + rung-2 work down to rung-3; rung-3 findings harden into rung-1 checks. Same flywheel improves quality + deflates unit cost — by design not by hope. *Canon 4 §41.*
- **C4-R-105 · Sequencing harness executes registered functions against fixture traffic in candidate orderings + measures real cost.** Deterministic gate is not simulated, it is run. Orderings optimised over registry cost + dependency fields. Rung-3/4 behaviour measured statistically, never claimed exact. *Canon 4 §42.*
- **C4-R-106 · Every technique adoption made on measured evidence from platform's own material.** Published optimiser results at large-scale pretraining do not transfer automatically to adapter fine-tuning on enterprise estate. *Canon 4 §43.*
- **C4-R-107 · Training-recipe seat versioned + ledgered configuration.** Optimiser + params + LR schedule + batch/epoch + adapter rank + target modules. Ships empty — no default recipe exists until first real training run. *Canon 4 §43.1.*
- **C4-R-108 · Every trained model registry entry cites recipe version.** Extending lineage criterion of acceptance by this field. Revisions are DEFAULT-class (no ceremony) but every revision attaches measured comparison + writes ledger row; revision with no attached evidence = defect. *Canon 4 §43.1.*
- **C4-R-109 · Foundation methods are fixed as FACT.** LoRA + PEFT adapters on registered open base models · training material from de-duplicated cleaned qualified units only · acceptance exclusively through 6 MOAC criteria on uncurated held-out sets. *Canon 4 §43.1.*
- **C4-R-110 · Optimizer adoption protocol.** One two-arm comparison at first adapter training on real material: baseline vs candidate · identical data/base/eval/compute · smallest stratum yielding valid acceptance eval. Quality parity mandatory for eligibility; compute-to-convergence reported not gating; no adoption threshold in advance — decision on measured results. *Canon 4 §43.2.*
- **C4-R-111 · Winning arm becomes new recipe with comparison attached; loser recorded as tested with numbers, permanently.** *Canon 4 §43.2.*
- **C4-R-112 · Ensembles legitimate for detection, prohibited for decision.** Multiple reviewers may surface findings; no collection of models holds decision authority. Detection-never-decides. *Canon 4 §43.3.*
- **C4-R-113 · Ensemble deployment discipline.** Deploys only where rubric + context repair tried and repaired single critic still misses on subsequent audit · independence mandatory (different base model or materially different context shape) · all output is findings never a vote · disagreement = finding class routed to standard ruling process. *Canon 4 §43.3.*
- **C4-R-114 · Ensembles bounded at three members without explicit escalation.** Cost-per-review telemetry emitted per member; ensemble retires if gain over single repaired critic falls under ten points after one full calibration cycle. *Canon 4 §43.3.*
- **C4-R-115 · Local-cascade offload builds only against demonstrated cost pressure.** No cascade scaffolding, draft-model acquisition, or routing machinery before metered telemetry on a named seam shows spend exceeding threshold set at that time. *Canon 4 §43.4.*
- **C4-R-116 · Cascade shape.** Local model drafts · deterministic acceptance check decides · frontier invoked only on rejects. Acceptance check is rung-1 machinery, not a second model's judgement. Cascade emits double-pay rate from first run; retires if escalation makes it net-negative. *Canon 4 §43.4.*

## Part IX · Quality Across Every Output

- **C4-R-117 · Quality matrix keyed by output class, never media/customer/instance.** Every class carries same 4 dimensions instrumented same way: stratified human-verified sample from census composition, uncurated, thresholds evidence-classed, drift-watched continuously. *Canon 4 §44.*
- **C4-R-118 · Watch detection classes carry rows in same matrix.** Correctness = detection rate per signal class; loss = missed-detection rate; precision = false-positive cost against friction budget; attribution = verdict replay fidelity. One matrix, every output class, including classes that watch the others. *Canon 4 §44.*
- **C4-R-119 · Four dimensions.** Correctness (measured per class in native unit — WER for speech, F1 for tags, etc.) · Loss (unrecoverable defect class · bounded tightest of the four) · Precision (wrongly included/over-applied) · Attribution fidelity (who/where/when preserved through transformation). *Canon 4 §44.*
- **C4-R-120 · Census activates matrix rows.** Class with no material in estate stays dormant — registered, instrumented on paper, zero build; class census observes activates: checkpoints join first-measurement sample, thresholds bind before production mining. *Canon 4 §44.*
- **C4-R-121 · Speech = ruled standard, never diluted.** WER ≤ 15% clean / ≤ 25% degraded telephone/archival / ≤ 30% code-switched · diarisation error ≤ 20% multi-speaker — all NORM. VAD false-negative loss ≤ 1% DEFAULT (stratified sample weighted to quiet speakers/vernacular/degraded). Language-ID routing ≥ 98% DEFAULT with misroutes tagged. De-identification recall ≥ 99% NORM on seeded personal-data sample. *Canon 4 §45.*
- **C4-R-122 · Non-speech classes carry definitions but activation sets thresholds.** Documents/images/video/analytic outputs — thresholds set at activation from that class's literature, never invented in advance of any material to measure. *Canon 4 §45.*
- **C4-R-123 · Structured-mapping measured per connector at onboarding.** Human-verified sample proving mapping before census carrying that connector publishes at all. *Canon 4 §45.*
- **C4-R-124 · Analytic outputs carry absolute per-class baselines.** Summarisation additionally checked for faithfulness — no claim in summary may be absent from its sources. *Canon 4 §45.*
- **C4-R-125 · Derived artefacts add completeness sampling.** Briefs/claim graphs/datasets/occurrence indexes — completeness = does artefact contain what corpus actually supports, measured as miss rate, never assumed zero. *Canon 4 §45.*
- **C4-R-126 · Every threshold-validating sample uncurated, from measured census composition.** Engineering inputs = legitimate craft; touching verdict sample = illegitimate regardless of intention. *Canon 4 §45.*
- **C4-R-127 · MOAC six criteria (§46).** M-a Improvement (≥5% relative over base on target stratum) · M-b No collateral regression (≤1pp absolute on any non-target stratum) · M-c Uncurated evaluation (held-out census-stratified) · M-d Complete lineage (training-data unit set + licence-class inheritance binding + base checksum + adapter version pinned) · M-e Calibration (measured + versioned before scores feed any downstream gate) · M-f Evaluation card (customer-deliverable model ships with measured numbers whatever they are). *Canon 4 §46.*
