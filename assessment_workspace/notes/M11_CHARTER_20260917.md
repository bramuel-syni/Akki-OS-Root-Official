- **New files**:
  - `backend/services/data/repository.py` — the primitive.
  - For each M9 module that currently owns a shape-only carrier, a sibling `<module>_repo.py` in the SAME package that: (i) calls the M9 refuser first, (ii) then calls `Repository.<op>`. Sole importer of the sibling is that package's `__init__.py` boundary.
- **AST negative-scan tests** (RED first):
  - `test_data_layer_ast_sole_motor_importer` — only `services/data/repository.py` may `from motor.motor_asyncio import AsyncIOMotorClient` (or equivalent).

  - `test_m9_repo_siblings_call_refuser_before_repo` — bytecode-level check: every `*_repo.py` function invokes the paired refuser call site prior to `Repository.<op>` call site.
- **Module-count impact**: **DOUBLED for M9 packages** (agent-flagged cost).
