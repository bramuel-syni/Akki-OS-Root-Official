## §A · The Policies (§3, Table 0 verbatim)

| ID | Name | Subjects → Objects → Operations · Rule (verbatim) |
|---|---|---|
| **SFP-1** | Assertion Floor | S: any principal requesting a composed answer. O: the claim being composed. Ops: assert, compose, refuse. Rule: no sentence enters a composed answer without a per-sentence anchor to material; an unanchorable sentence is refused, not weakened (Doc 4 A2, A5.5). |
| **SFP-2** | Certainty-to-Evidence Binding | S: Watch response function (Mkono). O: severance authority. Ops: unlock, withhold. Rule: severance unlocks only from the closed six-signal registry; no confidence score, however high, is an eligible input (Doc 3 A5.2). |
| **SFP-3** | Acceptance Floor | S: any training run. O: model output. Ops: accept, refuse. Rule: every stated criterion satisfied or the run is refused in full; no partial acceptance (Promise #22, MOAC). |
| **SFP-4** | Custody Floor | S: any data crossing the chokepoint. O: the crossing itself. Ops: cross, de-identify, re-identify. Rule: no asset crosses without de-identification appropriate to its custody class (Promise #1, A5.1–A5.3). |
| **SFP-5** | Non-Conformance Ceiling | S: any actor whose behavioural signature drifts from declared conduct. O: the actor's trust discount. Ops: reduce, revoke. Rule: loss of conformance alone returns an actor to baseline verification; it is never, by itself, grounds for conviction (Doc 3 A5.7). |
| **SFP-6** | Release Budget | S: all external parties, jointly and severally. O: the estate's total information release. Ops: release, refuse. Rule: total release across all parties, operations, and time is bounded; exceeding it is a floor violation, not a negotiable ceiling (DAP-35). |
| **SFP-7** | Reproduction Ceiling | S: any artefact or output leaving a component boundary. O: controlled-unit content. Ops: egress, refuse. Rule: no artefact or output passes carrying reproduction of a controlled unit above the ruled threshold (DAP-31, A5.15). |
