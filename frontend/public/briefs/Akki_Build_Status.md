## Direct answer on percentage

**A defensible overall completion percentage is not established.** This is a
reporting gap, not a claim that nothing has been built. It would be misleading to
describe Akki as 80%, 90% or almost complete from the present records.

The current materials do not provide a current requirement-by-requirement closure
ledger with an agreed adopted denominator and evidence of real completion. We must
not convert test count, code volume, source-markup coverage or an endpoint existing
into a product-completion percentage. Nor should every completed component be
counted as zero merely because live integration is missing.

## Completion must be earned against established requirements

For each adopted requirement, record:
1. The exact obligation and source/ruling version; exclude nonclaims and duplicates
   only with an explicit explanation, never to improve the score.
2. The responsible capability and all mandatory consuming/producing components.
3. Whether implementation covers the whole obligation, including failure behaviour.
4. Whether its real frontend/backend/native handoffs are connected where applicable.
5. Whether the actual permitted source/model/effect is demonstrated when required.
6. Whether the user can complete the promised journey with the required authority,
   performance, quality and recovery guarantees.
7. Verifiable acceptance evidence, remaining gap and accountable next action.

Build against those requirements. Verification follows and can reopen a requirement
when it disproves completion. Existing tests are not permission to redefine the
requirement to match a passing implementation.

When the adopted denominator and current row-level closures are reconciled, report
an unweighted accepted-requirement ratio with its date and limitations. If an
effort-weighted delivery estimate is also useful, label it separately and publish
its weights before scoring. Never mix “implemented”, “integrated” and “accepted”
into one opaque percent or apply arbitrary half-credit to all partial rows.
