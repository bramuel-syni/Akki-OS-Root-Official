Verify language, speaker split, licensing, consent, annotation quality and independence before any use; do not quote unverified public MOS/WER as achieved or transferable.

## Output-specific acceptance derivation

| Output | Existing standard to recover/apply | Comparative test |
|---|---|---|
| Deck | Assertion titles form narrative; evidence proves claims; audience/register/style law; no clipping; coherent charts; retained notes/receipts; deterministic re-render | Same brief/source set; blind narrative/design/usability judgment; editable content and export inspection; compare native PPTX expectations against disclosed fallback behavior |
| Report | Answer-first, factual grounding, inspectable sources, useful limitations and decisions, self-contained reading | Claim/citation audit and blinded decision usefulness; source freshness/conflict handling; revise and export without changing numbers |
| White paper | WPW event provenance, actual methods/baselines, held-out results, all criteria, limitations, novelty chain, publication redaction | Replay accepted and refused experiments, figure-to-run trace, missing evidence refusal, matched paper review; no invented innovation |
| Board artifact | Decision requested, alternatives, costs/risks, recommendations and accountable follow-up | Director-style blind reading: can the requested decision be made without author narration? Every supporting figure reconciles |
| Executive brief | Correct compression of decision/evidence/uncertainty/next action | Compare with full evidence: no dropped critical caveats or manufactured certainty; audience time-to-understanding measured |
| Workbook | Real editable assumptions, recalculated formulas, source/claim agreement, explicit scenario boundaries | Recalculate, perturb assumptions, reconcile deck/report totals, no formula errors, no frozen screenshots posing as data |
| Spoken story | AIP language-character fidelity + newly activated rendering, intelligible and expressive narrative, distinct synthetic identity | Native-language blinded listening on unseen texts; calibrated acoustic/semantic diagnostics; corpus-scoped identity distance; no isolated spectrum-only pass |
| Radio listener | Correct/time-aligned brand events under actual broadcast conditions with provenance | Per-language/stratum precision/recall, missed/false mentions, switch/timing/coverage/latency; hard negatives and repeated-broadcast split isolation |
| Model-maker interaction | Familiar commission/draft/refine, persistent context, progress, cancellation and retrieval | Same end-user task on named reference and Akki; no lost sessions/work or hidden manual engineering steps |

**Pass principle:** meet the existing prescribed absolute standard AND demonstrate same-or-better performance against the declared matched reference where that comparative claim is made. Use real reference artifacts when available. A vendor web page cannot supply a reference-output score. If account/access or an independent reviewer is missing, mark that comparison not yet run; do not invent a pass. Keep full tokens/compute/retry/review/storage/human-edit cost per accepted output. No assumed percentage savings.
