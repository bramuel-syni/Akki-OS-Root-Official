# Brief — six dimensions for a training commission
| Dimension | What it decides here | Field |
|---|---|---|
| Purpose | Always `train`; the statement names the task and the consumer of the model | `purpose` |
| Audience | The objective owner and the Owner seat; their priorities drive report emphasis (cost first, or strata first) | `audience` |
| Setting | Staged reporting vs one report; read unattended means every stage report stands alone | `setting` |
| Content | Whether materials, a sealed test set, a baseline and a rights declaration exist; if any is missing the commission is not admissible yet | `content` |
| Brand/tone | Report house voice | `brand` |
| Outputs | run-record, report-md, moac-pack | `outputs` |
| Constraints | Budget cap, compute class, gate policy (default `gates`, A17.19b), min group N (`platform_seam`, A17.19a) | `constraints` |
Manifest entries cite these fields; a change to one is a strike.
